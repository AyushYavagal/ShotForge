# ShotForge

ShotForge is a Blender add-on that turns a simple shot list into cameras and timeline markers.

## Features

- Create editable storyboard shot cards
- Set shot type, duration, and subject
- Generate cameras for each shot
- Aim cameras at selected subjects
- Create timeline markers for each shot
- Bind markers to cameras
- Update storyboard without duplicating old cameras
- Clear generated storyboard setup

## Installation

1. Download `shotforge.py`
2. Open Blender
3. Go to `Edit > Preferences > Add-ons`
4. Click `Install`
5. Select `shotforge.py`
6. Enable the add-on
7. Open the sidebar in the 3D Viewport and go to the `ShotForge` tab

## Usage

1. Choose a shot type
2. Set duration
3. Choose a subject object
4. Click `Add Shot`
5. Repeat for more shots
6. Click `Update Storyboard`

ShotForge will create cameras and timeline markers based on your shot list.

## Current Limitations

- Camera positions are simple presets
- Generated cameras are basic starting points, not final compositions
- The add-on does not generate full scene blockouts yet
